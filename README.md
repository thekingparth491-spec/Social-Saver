# SocialSave

Self-hosted video downloader for **YouTube, Instagram, Facebook** and a **WhatsApp status saver**. Node/Express backend wrapping [yt-dlp](https://github.com/yt-dlp/yt-dlp), with a mobile-first single-page frontend.

> Use it only for content you own or have permission to download. Respect each platform's terms and local copyright law. You are responsible for how you use it.

## Quick start

```bash
# 1. Prerequisites: Node 18+, yt-dlp, ffmpeg (required for HD merge and mp3)
pip install -U yt-dlp        # or: brew install yt-dlp

# 2. Install and run
git clone https://github.com/<you>/socialsave.git && cd socialsave
cp .env.example .env
npm install
npm start                    # http://localhost:3000
```

Docker: `docker build -t socialsave . && docker run -p 3000:3000 socialsave`

## Frontend

React 18 + Vite + Tailwind + Framer Motion, built into `public/` (already committed, so `npm start` works as is).

| Component | Role |
|---|---|
| `SlidingTabs` | Segmented control, spring-animated active pill (`layoutId`) |
| `ChipGroup` | Quality, format and bitrate chips with a gliding selection ring |
| `UrlInput` | Glass input with paste button and focus glow |
| `MediaCard` | Thumbnail, title, video/audio panels swapped with `AnimatePresence` |
| `ProgressCard` | Spring-driven progress bar and a drawn checkmark on completion |
| `WhatsAppGrid` | Staggered grid of status files |

Motion respects `prefers-reduced-motion` through `MotionConfig`. To edit the UI: `npm run dev:client` (port 5173, proxies `/api` to the server), then `npm run build`.

## Backend index

| Method | Endpoint | Purpose | Params |
|---|---|---|---|
| GET | `/api/health` | Liveness + WhatsApp enabled flag | none |
| POST | `/api/info` | Title, thumbnail, duration, available heights | JSON `{ "url": "..." }` |
| POST | `/api/prepare` | Starts a download job, returns `{ id }` | JSON `{ url, type: "video"\|"audio", height?, format?, bitrate? }` |
| GET | `/api/progress/:id` | Job status: `running`, `done`, `error`, plus `percent` and `stage` | none |
| GET | `/api/file/:id` | Sends the finished file as an attachment | none |
| GET | `/api/whatsapp/list` | Lists files in `WA_STATUS_DIR`, newest first | none |
| GET | `/api/whatsapp/file/:name` | Preview a status file; add `?dl=1` to download | `name` |

**Video:** `height` caps resolution (e.g. `1080`); omit for best. Video and audio streams are merged into MP4 with ffmpeg.
**Audio:** `format` is `mp3`, `m4a`, `opus` or `wav`; `bitrate` is `64`, `128`, `192`, `256` or `320`.
Jobs and temp files are deleted after 20 minutes.

Errors return `{ "error": "message" }` with 400 (bad URL), 501 (WhatsApp not configured), 502 (yt-dlp failure).

### Supported hosts
`youtube.com`, `youtu.be`, `instagram.com`, `facebook.com`, `fb.watch`, `fb.com`. Anything else is rejected before yt-dlp runs.

### Configuration (`.env`)
| Variable | Default | Meaning |
|---|---|---|
| `PORT` | `3000` | HTTP port |
| `YTDLP_PATH` | `yt-dlp` | yt-dlp binary location |
| `WA_STATUS_DIR` | empty | Folder with WhatsApp status files; enables the WhatsApp tab |
| `FFMPEG_PATH` | empty | Folder containing ffmpeg, if not on PATH |
| `APIFY_TOKEN` | empty | Enables the Apify fallback (see below) |
| `RATE_LIMIT` | `20` | Info/prepare requests per minute per IP |

## Fallback: Apify `andryerica/all-video-downloader`
yt-dlp is always tried first. If it fails (blocked, outdated, unsupported link) and `APIFY_TOKEN` is set, the server calls the [Apify actor](https://apify.com/andryerica/all-video-downloader) with `{ url, max_formats }`, picks a format from the direct links it returns, and saves it through the same progress flow. `/api/info` reports which one answered in `provider` (`yt-dlp` or `apify`).

Limits: Apify bills per run to your account, files keep their original format (no mp3/bitrate conversion), and quality choices depend on what the actor returns. Without a token this path is off.

## WhatsApp status
WhatsApp has no public API, so statuses are read from disk. View a status in WhatsApp first so it gets cached, then point `WA_STATUS_DIR` at the folder:

- Android: `/storage/emulated/0/Android/media/com.whatsapp/WhatsApp/Media/.Statuses` (older: `/WhatsApp/Media/.Statuses`). Run the server on the phone with Termux, or sync the folder to your machine.
- Desktop: copy the folder to your computer and set the path.

## Notes
- Private or login-only posts need cookies: add `--cookies cookies.txt` to the yt-dlp args in `server.js`.
- Keep yt-dlp updated (`yt-dlp -U`); platforms change often and old versions break.
- Put it behind HTTPS and keep the rate limit on if you expose it publicly.
